# Замер скорости скачивания

Консольный скрипт на Python. Делает 10 последовательных запросов к указанному
адресу, полностью скачивает ответ на каждый и выводит статистику.

## Требования

- Python 3.8+
- Внешние библиотеки не нужны (используется только стандартная библиотека)

## Запуск

```bash
python speedtest.py <URL>
```

Пример:

```bash
python speedtest.py "https://speed.cloudflare.com/__down?bytes=10000000"
```

Подойдёт любой адрес с достаточно «тяжёлым» файлом (картинка, архив и т.д.).

## Что выводится

- время и размер каждого запроса;
- среднее время запроса (в секундах);
- общий объём скачанных данных (в мегабайтах);
- скорость скачивания.

## Единицы измерения

- **Скорость:** Мбит/с (мегабиты в секунду), дополнительно показывается в МБ/с.
- **Объём данных:** МБ (мегабайты).
- **Время:** секунды.

В расчётах используются десятичные приставки: 1 МБ = 1 000 000 байт, 1 байт = 8 бит.
Мбит/с выбран потому, что именно в нём провайдеры указывают скорость интернета.

## Как считается скорость

```
скорость (Мбит/с) = (всего байт × 8) / суммарное время всех запросов / 1 000 000
```

Время каждого запроса измеряется от отправки запроса до получения последнего
байта ответа.

## Обработка ошибок

При ошибке сети, таймауте (30 с) или HTTP-ошибке (404, 500 и т.п.) скрипт
печатает сообщение в stderr и завершается с кодом 1.
